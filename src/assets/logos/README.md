# Project logos

Logos for QUESTING, Q-FENCE, BRAINET and COALESCE are taken from the project
websites each time the site is built (the addresses are the `logo` lines in
`src/data/projects.ts`). If a website cannot be reached, that project shows its
icon until the next build.

To add a logo for any other project, or to replace one, upload the image here
and name it after the project, in lower case, with spaces and symbols turned
into hyphens:

| Project       | File name                  |
| ------------- | -------------------------- |
| ENACT         | `enact.png`                |
| PlastG        | `plastg.svg`               |
| AIQ-Shield    | `aiq-shield.png`           |
| ABM QuantumNet| `abm-quantumnet.png`       |

SVG, PNG, JPG and WebP all work. Empty margins are trimmed automatically, and
a white logo on a transparent background is shown on navy so it stays
visible. A file uploaded here is used in place of the website's logo.
